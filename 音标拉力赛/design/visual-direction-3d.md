## A. 视觉身份

### A.1 一句话定位

> **「一张会动的羊皮纸藏宝图」**——把 D1 的探险地图折成一台 pop-up 立体书，玩家跟在探险卡丁车后面，沿着暗红虚线往纸的深处开。

不是「把 2D 小游戏升级成写实赛车」，也不是「塑料感卡丁车 + 羊皮纸贴图」。参照气质：博物馆立体书、微缩沙盘、手绘地图模型、桌游配件；**不是**手游竞速、不是皮克斯、不是低多边形玩具。

### A.2 三条视觉支柱

1. **纸感优先于真实感（Paper over Physics）**：一切 3D 表面先像「纸浆 / 石灰 / 木板压出来的」，再像车和石头。远景一律向羊皮纸色 `#e7d3a8` 雾化收敛——赛道不是消失在雾里，是**消失回纸里**。这是本作在 3D 时代区别于所有竞速游戏的唯一识别符。
2. **刻线而非描边（Engraved, not Outlined）**：墨线靠**几何凹槽 + AO** 成立，烫金靠**真实倒角 + 金属材质**成立，纸纹靠**粗糙度微扰**成立。任何「贴在物体表面的一层效果」都要被翻译成「物体本身的材质/结构」，否则立刻显脏、显廉价（§A.4）。
3. **宝石即信息（Gem = Signal）**：红/绿/蓝三宝石是全世界唯一允许的高饱和色，且**只承载教学语义与关键交互**（车道、对错、解锁、地标）。其余一律暖灰、米、墨蓝、纸棕。颜色少 → 精致；颜色有含义 → 不低幼。

### A.3 情绪板关键词

`做旧羊皮纸` `pop-up 立体书` `铜版蚀刻` `烫金压印` `墨蓝凹刻` `微缩沙盘` `清晨/午后暖光` `纸雾` `罗盘玫瑰` `宝石菱形徽章` `暗红虚线路径` `探险日志` `克制` `留白` `知识感`

反义关键词（明确排除）：`糖果色` `镜面烤漆` `塑料清漆` `霓虹` `全屏辉光` `脏污做旧` `写实照片` `满屏黑边` `Q 版卖萌三头身大头` `低幼卡通`

### A.4 核心难题：2D 平面语言 → 3D 材质，怎样不显脏、不显廉价

这是本次升级最容易翻车的地方。逐项给出**具体材质做法**（PBR 参数为 WebGL 口径；括号内为 2D canvas 伪透视的等价烘焙做法）：

| 2D 语言 | 直接搬到 3D 会怎样（失败模式） | **正确做法（材质规格）** |
|---|---|---|
| **纸纹**：2D 是 1400 条随机短线的全屏噪声（`render.js:19–26`） | 把噪声贴图铺到所有 3D 表面 → 远处 mip 采样产生**摩尔纹 / 闪烁（shimmering）**，斜视角下像**霉斑、灰尘、油渍**；暗色 multiply 叠满物体 = 显脏第一元凶 | ① **纸纹只留在两个地方**：天空穹顶 / 远雾背景，以及 HUD、牌面、贴花这类**正交 2D 平面**（无透视、无 mip 闪烁）。② **3D 表面禁用颜色噪声**：改用 `roughness 0.78–0.9` 的哑光基底 + 振幅 ≤3% 的低频粗糙度微扰（normal 只给 ≤2% 强度），并随距离 mip 淡出；`metalness = 0`。③ 明暗靠**单一暖主光 + 柔和补光 + 轻 AO**，不靠脏贴图。（2D：纸纹只画在背景层一次，物体上是纯色 + 一层暖渐变高光，绝不逐帧叠噪声。）④ 硬规则：**英雄资产（卡丁车、精灵徽章）上不允许任何深色噪声/污渍/水痕**。 |
| **金线**：2D 是 2–3px 的 `--line/--gold` 描边 | ① 在 3D 里画成发光描边 → 高速下闪烁、像廉价 UI 光效；② 整车/整墙做成镜面金 → 「土豪金 bling」，塑料感爆表 | 翻译成**「烫金压印 / 箔印」（foil stamping）**：做成**真实几何**——倒角(chamfer)、凸起细饰条、凹槽内嵌金箔，而不是画上去的线。材质 `metalness 0.7–0.85`、`roughness 0.3–0.4`、`base #c9a227`，高光走 `#c9a227 → #f0d78c` 的渐变（**用渐变贴图，不用镜面反射**），各向异性轻微。用量克制：**每个物体 ≤3 处烫金**（如轮毂中心盖 + 车头饰条 + 尾翼缘），总面积 <5%。（2D：一条 2px 深金底线 + 一条 1px 亮金高光线，模拟压印的「暗边+亮面」。） |
| **墨线**：2D 是粗细变化的手绘钢笔线 `#23364E` | 全场景套 uniform 反壳描边（inverted hull）→ 满屏黑边、像廉价卡通渲染；纯黑线在暖纸上发死 | ① **建筑 / 护栏 / 地标**：墨线 = **几何嵌线**——在模型上开 1–2cm 深的凹槽，槽底 `#23364E` 哑光（`roughness 0.95`），靠 AO 自然变暗；这是「刻」不是「描」。② **卡丁车 / 角色**：允许保留**一条**克制的外轮廓，颜色 `#23364E`（**不用纯黑**），375px 下线宽 1.5–2.5px，轮廓转折处轻微加粗（继承钢笔的粗细变化），随距离淡出；**只给主角与车，不给每个道具**。③ 暗红虚线路径 `#8C4034` 作为地面贴花常驻，是连接 2D 世界最强的连续性符号。（2D：现有 1.5px `--line` 描边逻辑保留。） |
| **整体防廉价四条** | — | ① 单一暖主光，**禁止**多光源硬高光点与全屏 bloom；② 全局轻降饱和 + 暖色分级（把 3D「压回纸上」）；③ 金属只用于烫金与轮毂，轮胎/车身一律非金属；④ 留白 ≥15%，四区地标各自独占天际线，不堆装饰。 |

> **【方案甲权重标注 · 用户已拍板】** 上表材质权重**按「方案甲 · 立体书」执行**：以「哑光纸浆 / 石灰 / 木质 + 轻 AO + 纸雾收敛」为基准，烫金只在少量倒角、墨线靠几何嵌线，**平面层全 2D**；即 `roughness 0.78–0.9`、`metalness = 0`（仅烫金 0.7–0.85）、纸纹只留在天空穹顶与正交 2D 平面。方案乙「微缩沙盘」会要求材质更实、金属与镜面更多、光照更立体——**本轮不采用**，仅作对照（附录 6）。

### A.5 继承 / 升级关系小结

- **继承**：色板与三宝石语义、四区世界观、罗盘/卷草纹、暗红虚线、Q 版 2.5 头身、无字底版、留白、不低幼。
- **升级**：平面 → 体积；描边 → 刻线；静态噪声 → 粗糙度微扰；全景俯视 → 跟车纵深；**但 HUD / 牌面 / 贴花 / 转场仍是纯 2D 平面**，让「纸」始终在场。

## B. 摄像机与空间

> **首要矛盾（必须诚实面对）**：本作核心玩法是「听音 → 把车开进左/右正确车道」，玩家**必须同时看见两条车道与前方路牌**。典型竞速游戏的低机位贴地跟车会压掉远车道和路牌。因此本作不采用低机位，采用 **「高追尾 / 略俯跟车」（high chase）**——仍完全满足「车在近处、赛道向远处消失、看不到全景、分叉靠前方预告」，但纵向视野更宽。这是玩法对美术的硬约束，不是妥协。

### B.1 推荐参数

| 参数 | 375px 竖屏（触屏优先） | PC / 横屏 | 说明 |
|---|---|---|---|
| 机位高度 | **3.4–3.8 m**（≈ 车高 4×） | 2.8–3.2 m | 高机位是两车道可读的前提 |
| 俯角（pitch down） | **16°–20°** | 12°–16° | 高于常规竞速（5–10°），换取纵深里的车道分辨 |
| 跟车距离 | **7.0–8.5 m** | 5.5–7.0 m | 车长约 1.6 m，即 4–5 个车身 |
| 视场角 | 锁**水平 FOV 60–66°**，垂直随屏扩展 | 水平 FOV 60–66° | 避免竖屏硬套垂直 FOV 导致赛道过窄 |
| 消失点位置 | **画面顶部起 38%–42%** | 40%–44% | 略高于中线；下方 58–62% 给路面与车，上方给天际线/地标 |
| 注视点（look-at） | 车前方 8–10 m 沿赛道切线 | 车前方 6–10 m | 让镜头「看向路」而非平视 |
| 位置阻尼 | 临界阻尼弹簧，时间常数 **0.18–0.28 s** | 同 | 禁止逐帧硬跟随（晕） |
| 偏航阻尼 | **0.25–0.35 s** | 同 | 转弯时车先转、镜头稍后跟上，产生跟车感 |
| 抖动 | 仅 boost / 碰撞触发，≤2–3px @375px、≤0.4°，**无 >30Hz 高频分量** | 同 | **必须可关**（§H），复用现有 `reduced` 分支 |
| 转弯侧倾 | 镜头 **±2–4°**（0.15s lerp）；**车身自身 ±5–7°** | 同 | 动感主要给车，不给世界，防晕 |
| 速度感 | ① 近景护栏/道具滚动速率；② boost 时 FOV **+4–6°**（0.2s ease-in/out）；③ 屏幕**边缘**纸纤维流线（非全屏）；④ 轮毂转速 + 尾焰 + 现有 `drawRibbon` 彩带；⑤ 远层视差 | 同 | **禁止全屏径向模糊**（晕 + 毁可读性） |

### B.2 消失点与远景层次（纸雾收敛）

- **三层**：
  - **近层 0–12 m**：全对比、全饱和、完整烫金与墨线细节（护栏、路面宝石标记、车）。
  - **中层 12–45 m**：饱和 −10~15%、对比 −10%，开始混入天光色；路牌在此层出现并**保持屏幕空间最小尺寸**（不随距离无限缩小，见 §E）。
  - **远层 45 m+**：只留**地标剪影 + 天空穹顶**，指数雾 `FogColor = 本区天光色`（§D），最终收敛到 `#e7d3a8` 纸色。
- 天空穹顶是**唯一允许保留纸纹**的 3D 面（正交、无 mip 闪烁风险，§A.4）。
- **暗红虚线 `#8C4034` 地面路径**贯穿三层，是「我在往哪开」的第一视觉锚。

### B.3 看不到全景时，靠什么建立方位感（6 件，按重要性排序）

1. **右上角小地图**（本轮已拍板）：显示**该轮杯赛的闭环赛道**（不是四区大地图！沿用 `render.js:drawMinimap` 的环线语义），玩家点带朝向箭头、宝石点标下一门、外圈为**圈数进度环**。视觉规格见 §E。
2. **路牌预告**：只预告**下一个**分叉（两项 + 方向箭头），不暴露整条路线——这正是「只能靠前方预告判断」的实现。
3. **远景恒定地标**：每区 1 个始终可见的天际线地标（§D），充当「北极星」；转弯时它在天际线的左右位移即是方位。

## C. 卡丁车

### C.0 造型总纲：`探险卡丁`（`KART_TYPE`）

不是 F1、不是卡哇伊碰碰车，是**探险队用纸浆板 + 木框 + 铜件拼出来的小车**。共用底盘，三车手靠**剪影**区分——因为在 375px 跟车视角下，车只占屏高约 18–24%，且大部分时间看到的是**车尾**，细节与配色都不可靠，**只有轮廓可靠**。

- **比例**：长 : 宽 : 高 ≈ **1.6 : 1.0 : 0.85 m**；四轮 φ0.42 m；车手 Q 版 2.5 头身，头 φ≈0.32 m，坐姿只露头 + 肩 + 手臂（跟车视角可见后脑与肩线）。
- **通用件**：4 轮 + 5 辐轮毂（金色中心盖为唯一烫金点）、后视镜、行李架、`roundRect` 圆角车身语言（继承 `render.js` 的 `roundRect` 造型）、车头/车侧**空白编号牌**（数字后期合成）、车侧**菱形宝石徽章位**（空白容器，§C.5）。
- **配色分区（可复用公式）**：主色 60% / 羊皮纸奶白 `#f6ead0` 25% / 墨蓝 `#23364E` 10% / 烫金 `#c9a227` 5%。材质见 §A.4（车身 `metalness 0, roughness 0.75`；轮胎 `roughness 0.95`；座椅奶白哑光）。
- **三车手主色以 `config.js CHARACTERS[].body` 为唯一数据源**：波波队长 `#3d8eb8`、小 Q `#e0b44a`、咪咪 `#1e7a4f`。

> ⚠️ **一处必须处理的配色冲突**：小 Q 车身 `#e0b44a` 与烫金 `#c9a227` 色相/明度过近，若沿用「金色 trim」会糊成一片、丢失层次。**方向裁定：小 Q 车的 trim 改为墨蓝 `#23364E` 嵌线**（烫金仅保留轮毂中心盖 1 处）。现有 `render.js:382–386` 里 player 车 `#2f6f8f` + `#e0b44a` trim 的硬编码实现，3D 轮以 `config.js` 为准收敛。

### D.2 区与区之间的过渡手法

### E.2 描边 / 底板 / 圆角（统一「羊皮纸卡 + 墨线 + 烫金角」）

- 底板：`rgba(255,250,240,.96)`（现有 `--card` 的 `.94` 在 3D 高速背景上提到 `.96`）；圆角 12–16px（375px）/ 16–22px（PC）；沿用 `--shadow 0 10px 28px rgba(90,62,30,.2)`，3D 背景上加权到 `.28`。
- **双层描边（这是抗运动背景的关键）**：内层 `1.5px var(--line) #b99b6b` + 外层 `1px rgba(35,54,78,.35)` 墨蓝压线。亮区（peak 雪地）靠墨蓝压线分离，暗区（kingdom 砖路）靠米金线分离，任何背景都成立。
- 烫金角：卡片左上角一个 ≤6px 的小罗盘点/三角（`#c9a227`），**每卡最多 1 处**，只作质感不作装饰堆砌。

### E.3 在高速运动背景上保证可读（6 条硬规则）

1. **每个文本块自带不透明底板**，禁止把字直接压在 3D 画面上。
2. **双层描边**（§E.2），明暗背景通吃。
3. **局部纸雾 scrim**：小地图 / 进度条 / quiz 卡片后方各铺一层 `rgba(231,211,168,.55)` 的局部渐变，只覆盖 HUD 占位矩形，**不压暗整屏**（保留 3D 的精致感）。
4. **世界层在 HUD 占位区做轻微降饱和/亮度收敛**（材质参数，不改玩法）。
5. **屏幕 HUD 绝对静止**（不跟 shake / roll / FOV），速度感只给 L0–L1。
6. **禁止** HUD 半透明低于 .9、禁止 HUD 上叠加动效模糊。

## F. 技术承载双版本对比（只列视觉后果，选型由主理人 + 程基岩拍板）

### F.1 逐项对比

> **【方案甲纵深标注 · 用户已拍板】** 本节纵深强度**按「方案甲 · 立体书」执行**：跟车纵深以「纸雾收敛到羊皮纸色」为上限（远层 45 m+ 只留地标剪影 + 天空穹顶），**世界层轻 3D、平面层全 2D**，不追求方案乙「微缩沙盘」的强透视、强体积光与写实景深。下方两版对比只列视觉后果，技术选型本身留待下一轮拍板（附录 7）。

| 维度 | **真 WebGL**（模型 + 光照 + 阴影 + 后期） | **2D canvas 伪透视**（缩放精灵 + 色块 + 投影） |
|---|---|---|
| 透视与纵深 | 真实连续纵深、真消失点、转弯时护栏/建筑连续透视变化；路牌有真实远近 | 靠分层缩放 + 分段投影模拟；弯道易出现「纸片翻面 / 比例跳变」，纵深是**假**的，但 375px 小屏上可接受 |
| 纸纹 / 烫金 / 墨线材质 | 能真正实现 §A.4 的 roughness 微扰、金属箔印、几何凹槽 AO —— **「精致」的天花板在这里** | 只能把明暗**烘焙进贴图**：烫金 = 双色渐变线、墨线 = 1.5px 描边、纸纹 = 背景层一次；够用但无随视角变化的质感 |
| 光照 / 阴影 | 单一暖主光 + 软影 + AO 真实成立；§D.3 第 2 圈「主光 +25°」是**真影子变向** | 投影是固定椭圆（现有 `drawKart` 的 `rgba(40,28,12,.3)` 椭圆）；光照偏移只能靠全屏色温叠加，层次弱 |
| 卡丁车 / 角色 | 三车手剪影、侧倾、悬挂、轮毂、挂件摆动、副驾都成立 | 需预渲染多方向精灵帧；剪影仍可辨（**这是本作最吃紧也最该保住的一项**），但侧倾/挂件细节会丢 |
| 精灵贴花 / 现有资产 | 48 张 `.webp` 作为 decal 贴到徽章位，100% 复用 | 直接 `drawImage`，100% 复用（现有已如此） |
| 雾 / 远景收敛 | 指数雾把赛道「收回纸里」是**本作签名效果**，可精细控制三层 | 只能叠一层半透明纸色矩形，过渡较硬，但仍能表达 |
| 速度感 / 后期 | FOV 呼吸、边缘流线、轻 vignette 可控 | 只能靠粒子/彩带/缩放；无景深与边缘流线，速度感偏「卡通」 |
| **HUD 可读性** | 需严格按 §E 做 scrim 与双层描边（3D 背景更花） | 背景本就是平面，**天然最好读** |
| 与现有 2D 资产连续性 | 有断裂风险（§I.3），靠「平面层仍 2D」兜底 | **零断裂**，与 29 张成稿、48 张立绘、现有 CSS 完全同源 |
| 性能 / 375px 触屏 | 中低端机压力大，需 §H 三档降级；首屏体积与 WebGL 上下文是新增风险 | 现有架构已跑通，无新增依赖、无构建步骤，帧率最稳 |
| 与「无构建 / 静态站 / ESM」约束 | 需评估 GLB 懒加载、CACHE_TAG 缓存串、首屏体积（工程侧定） | 完全契合现状 |

### F.2 能保留 / 会失去 / 成本与风险（汇总）

- **真 WebGL** — *能保留*：连续纵深、真实纸雾收敛、烫金/墨线的材质级精致、真实光影与第 2 圈光照变化、三车手立体剪影。*会失去*：零构建/零依赖的极简架构、现有 2D 渲染逻辑的完全复用、低配机帧率冗余。*成本与风险*：建模 + 材质 + 光照 + 新缓存串 + 三档降级 + 新一轮 HUD scrim 适配；最大风险是**纸纹/烫金做错即显脏显廉价**（§A.4）与**与现有平面资产断裂**（§I.3）。
- **2D 伪透视** — *能保留*：100% 视觉一致性、全部现有资产、零构建、HUD 最佳可读、最低性能风险、可访问性降级最简单。*会失去*：材质真实感、连续光照/阴影、随视角变化的质感、以及「精致」的上限——用户「更精致美观」的诉求**只能部分兑现**。*成本与风险*：几乎零新增成本；风险是弯道纵深穿帮、以及「3D 化」承诺打折。

### F.3 美术方向建议（不替工程拍板）

1. **从纯视觉立场**：只有 WebGL 能完整兑现「跟车纵深 + 材质级精致 + 更精致美观」；伪透视的天花板是「一张更精致的 2D 立绘本」。这是**视觉后果**，不是技术结论。
2. **强烈建议采用「分层混合」**：**世界层**（赛道 / 远景 / 卡丁车）走 3D，**HUD / 路牌文字 / 小地图 / quiz 卡片 / 精灵贴花 / 转场 / 羊皮纸压边全部继续保持 2D DOM + Canvas 覆盖层**。理由：① 最省；② HUD 天然最好读（§E）；③ 符号后期合成的硬约束天然满足（§0.5）；④ 「纸」始终在场，一次解决断裂风险；⑤ 48 张资产零改动。
3. **无论选哪版，视觉验收基线一致**：必须同时满足 §A.4 材质三原则、§E.3 可读性 6 条、§H 可访问性矩阵。这条基线与技术选型解耦，可先冻结。

## H. 可访问性（分级 `A11Y-TIER: Standard → Comprehensive`）

> **本轮 2D HUD 底线 = Standard；发布后 3D 轮目标 = Comprehensive。** design-strategist 的 UX 规格须引用本分级与下表（§0.6）。可访问性是基础要求，不是锦上添花。

### H.1 特性矩阵

| 特性 | Standard（本轮底线，不可退让） | Comprehensive（3D 轮目标） |
|---|---|---|
| **色觉 / 色弱** | 不靠红绿区分左右车道；关键状态有色相外的第二通道 | 三宝石语义全量加形状/纹理冗余；提供「色觉友好」切换（红绿 → 蓝 `#2E5F8A` / 橙 `#D98E4A` + 纹理） |
| **动敏 / 前庭** | 镜头抖动、侧倾、FOV 呼吸、速度线**可一键全关**；默认跟随 `prefers-reduced-motion` | 关闭后速度感改由 HUD 数字 + 静态尾焰 + 路牌后移表达，镜头保持完全静止可预期 |
| **字号 / 对比度** | §E.4 全部下限；正文 ≥4.5:1、大字 ≥3:1、触控 ≥44×44 | 系统字体缩放 200% 不破版（关键文字移出 canvas 到 DOM） |
| **低视力** | 双层描边 + 不透明底板（§E.2/E.3） | 高对比模式（底板纯 `#fffaf0`、墨线加粗至 2.5px） |
| **光敏** | 禁止 >3Hz 全屏闪烁；confetti/闪光限区域、低亮度暖色 | 全部闪光效果可关，仅保留静态色块反馈 |
| **听觉 / 玩法冗余** | 保留「再听一次」；车道选项有图形与位置冗余 | ⚠️ 核心玩法是**听音选车道**，对听障用户需视觉冗余（显示目标词/口型提示）——**会改变玩法口径，已登记为下一轮需用户 + 设计侧共同拍板的独立议题，本轮不纳入**（附录 3） |
| **输入 / 运动** | 全部操作键盘 + 触屏可达；无长按/多指/精确拖拽硬依赖（现有「长按充氮」须提供点按替代） | 键位重映射；单手模式；触控热区可按左右手镜像 |
| **读屏 / 焦点** | 保留 `#live.sr` aria-live；模态层焦点陷阱 | 3D canvas 有等价文本描述；小地图有文本等价（「下一门在左前方」） |
| **低配降级** | 见 H.3 | 三档自动判定 + 手动覆盖 |

### H.2 色弱安全的具体做法（不靠红绿区分左右车道）

现状核对：拉力赛分叉用 **`is-long` `#1f618d` 蓝 / `is-short` `#b03a2e` 红**（`config.js` `A_COLOR/B_COLOR`），**本就不是红绿**，对红绿色盲相对友好；但 D1 的**三宝石语义含红/绿**（清/浊），kingdom 区的「清浊双塔」正是左红右绿 → **必须补冗余**：

1. **形状冗余**：长音/开张侧 = 长方形牌 + 双横线；短音/紧凑侧 = 圆形牌 + 单点；清浊双塔 = 左实线纹 / 右声带波纹；宝石菱形徽章用**朝向 + 边框实/虚 + 点数**区分，不只靠色。
2. **位置冗余**：左 / 右 + 方向箭头 + 车道地面标记，三者一致。
3. **图标/文字冗余**：例词首字母 + 对应精灵剪影（`Uxx.webp`），全部后期合成。
4. **亮度冗余**：两侧明度差 ≥30%，不只色相差。
5. 出图/上线前用**红绿色盲模拟**（protan / deutan / tritan）逐屏检查小地图玩家点、车道、对错反馈仍可辨。

### H.3 低配设备降级策略（三档，只减视觉不减信息）

| 档 | 视觉配置 | 判据（工程侧定，此处仅定义视觉档位） |
|---|---|---|
| **L2 全效果** | WebGL + 动态软影 + 三层纸雾 + 粒子 + 边缘流线 + 全贴图 | 高端 / PC |
| **L1 中** | 关动态阴影（改烘焙 AO）、DPR ≤1.5、粒子减半、远景静态图、关边缘流线 | 中端机 / 连续 3s 帧时间 >33ms 自动降 |
| **L0 低（回退）** | **切 2D 伪透视**（§F）：纯色块 + 固定椭圆投影，关闭一切后期与镜头运动 | 低端（deviceMemory ≤2GB）/ 手动 / `prefers-reduced-motion` 直接进此档动效子集 |

**硬底线**：任何档位都**不得**删减或缩小 —— 小地图、路牌预告、圈数、进度条、combo、quiz 卡片的可读性；**不得**缩小触控热区与字号。降级只减特效，不减信息与可访问性。

### H.4 与现有代码的低成本衔接（给工程侧的提示，非改动指令）

- `render.js` 已有 `reduced` 分支（`shake` 被置零）——动敏开关可**直接复用**，无需新增状态。
- `css/game.css` 已用 `env(safe-area-inset-bottom)`、`clamp()`、`min-height`——Standard 级大部分已具备，缺的是 `#hud button` 42×36 → 44×44 与 `.sign.on-lane .ipa` 下限 16px → 20px（§E.4），这两处属**本轮 2D HUD 范围**，交主理人转 #4 评估。
