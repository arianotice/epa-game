# 《声音探险队》图片体系 · 视觉规范 V1.0

> **主方向：D1 羊皮纸藏宝图 · 知识探险风**（2026-10-28 用户拍板锁定）
> 本规范是 Stage 2 全部 28 张定稿、后续 48 张身份卡及一切衍生视觉的唯一风格基准，任何生成不得偏离。D2「声音生物图鉴」留作备选，不进入本期生产。

---

## 1. 世界观与主体（不可变项）

- **四幕结构**：出发营地 → 元音城堡（20 元音）→ 辅音王国（28 辅音）→ 进阶峰。四区相对位置固定：营地左下、城堡居中、王国右侧、山峰右上。
- **48 个音标精灵**：每个音标一个拟人角色，形象暗合发音特征（如 /θ/ 吐舌精灵、/ŋ/ 打鼾国王、/s/ 小蛇、/iː/ 微笑小姐），以宝石菱形徽章作为承载容器。
- **双角色**：波波队长（呆萌可靠少年——探险帽 + 放大镜 + 深蓝斗篷）；小 Q（迷糊萌学生——圆脸 + 棕色卷发 + 小背包）。
- **口腔剖面四要素**：舌位 / 唇形 / 气流箭头 / 声带振动标记，每张含剖面的图必须四要素齐全。
- **总原则**：有趣味但不低幼（11–12 岁审美），知识感优先于可爱度。

## 2. 色板（精确值，全套统一）

| 角色 | 色值 | 用途 |
|---|---|---|
| 羊皮纸基底 | `#E9D8B4` | 所有图底色 |
| 做旧阴影 | `#C9AE82` / `#A88F63` | 纸张暗部、水渍、边缘焦痕 |
| 主线墨蓝 | `#23364E` | 钢笔主线、结构线、城堡/王国轮廓 |
| 辅线暗红 | `#8C4034` | 次级线稿、学习路径虚线、装饰纹 |
| 宝石·石榴红 | `#B03A2E` | 高亮：清音 / 短音 / 不振动侧 |
| 宝石·蓝宝石 | `#2E5F8A` | 高亮：长音 / 结构 / 路径 / 双元音滑动方向 |
| 宝石·翡翠绿 | `#2E7D5B` | 高亮：浊音 / 声带振动侧 |
| 角色暖色 | `#D98E4A` | 皮肤、火堆、暖调点缀（少量） |

**三宝石语义规则（硬约束，禁止混用）**：
- 红 = 清音 / 短音 / 紧凑侧
- 绿 = 浊音 / 声带振动侧
- 蓝 = 长音 / 拖长开张侧 / 结构与路径
- 无清浊对立的成对音（如 /m/-/n/、/w/-/j/）：红 = 第一音，蓝 = 第二音。

## 3. 材质与线条

- 基底：做旧羊皮纸——轻纹理、轻毛边、轻水渍；**禁止**干净白纸或纯色平涂底。
- 线条：钢笔手绘质感，主线深墨蓝带粗细变化，辅助线浅棕；**禁止**矢量等粗线。
- 装饰：罗盘玫瑰、卷草纹边框、四角小探险家/精灵头像；用量克制，不压信息层级。

## 4. 构图规则

- 地图式分区：四区位置固定，区域间用暗红虚线路径 + 脚印/箭头串联。
- 宝藏格：宝石菱形格 + 小图标，按教学分区密集排布；A1 全量 48 格（城堡区 20 + 王国区 28）。
- 信息层级：区域结构 > 宝藏格/剖面 > 装饰纹样；整图留白 ≥ 15%。
- 期配图（B 系列）：上部 1/3 生活场景插画 + 中央左右剖面对比 + 徽章位/单词气泡/口诀横幅，横版卡片构图。

## 5. 角色规范

- 比例：Q 版 2.5 头身；大眼但不夸张卖萌，表情有性格。
- 波波队长：探险帽 + 放大镜 + 深蓝斗篷，动作可靠元气。
- 小 Q：圆脸 + 棕色卷发 + 小背包，动作迷糊慢半拍。
- 48 精灵：每只一个主色（限于三宝石 + 暖色体系），造型一句话可描述、有记忆点。

## 6. 口腔剖面规范（专业内核）

- 侧脸剖面：圆润卡通线条，头部侧面 45° 剖切，占画面比例适中。
- 四要素标注：舌位（宝石色填充 + 引线）、唇形（线条姿态）、气流（箭头）、声带（振动波纹 = 浊 / 叉号 = 清）。
- 整体气质：羊皮纸上的「机械剖面墨线图」——专业但不医学化，引线末端预留标注位（无字）。
- **禁止**：写实医学插图、内脏细节、血腥感。

## 7. 文字与符号策略（硬约束）

- AI 生成一律**无字底版**：音标符号、中文、英文单词全部后期精确合成，禁止依赖 AI 直渲（乱码风险）。
- 预留位规范：音标徽章（圆形/菱形）、单词气泡（圆角框）、口诀横幅（飘带）——只画容器不画字。
- 正式交付：PNG、无水印；探索稿水印不进入定稿。

## 8. 验收清单（每张必查）

1. 羊皮纸质感成立，三宝石语义色使用正确
2. 四区/路径结构清晰可读（A 系列）；剖面对比关系明确（B 系列）
3. 角色符合第 5 节规范
4. 剖面四要素齐全（含剖面的图）
5. 无乱码文字、字母、数字
6. 无水印
7. 不低稚、不老气，留白充足
