## 3. 五类陷阱 · 汇总裁决与教学口径说明

### 3.1 A · 长短音 vs 紧松音（**命中 86 行：表 A 5 + 表 B 67 + 表 C 9 + 表 D 5**）

**问题**：英式 `/iː i/`、`/uː ʊ/`、`/ɑː ʌ/`、`/ɔː ɒ/` 用「长/短」区分；GA 中对应 `/i ɪ/`、`/u ʊ/`、`/ɑ ʌ/`、`/ɔ ɑ/` 是 **tense–lax（紧/松）** 对立，差别在肌肉紧张度、舌位高低前后、唇形；时长只是**伴随**线索（且随重音、后接辅音清浊大幅变化，不是稳定判据）。仅换符号不改措辞，会同时造成两种错误：
1. 儿童把「拖长」当成发音方法去练（`:1133` 甚至逐字定义「长，就是可以一直吹下去」）；
2. 换掉长音符后仍写「又长又开」，与大字 `/i/` `/u/` 自相矛盾（A2）。

**✅ 最终裁决（用户拍板 · 已定稿）：本轮采用口径 A（紧松为主）。口径 B / C 不采用，仅保留排除理由备查。**

| 口径 | 定稿结论 | 做法 / 排除理由 |
|---|---|---|

### 3.3 C · rhotic 卷舌（**命中 4 个 unit / 46 行：表 A 20 + 表 B 26**）

**核心裁决（本轮最重要的教学判断）**：

| unit | 英式 | 美式 | 英式教法 | 美式应为 | 是否冲突 |
|---|---|---|---|---|---|
| U11 | `ɜː` | `ɜr` | 「舌头卷成小弹簧**停在口腔中部**」「把声音拉长」 | 短元音 `ɜ` + **r 卷舌尾**（bird / girl / nurse） | **冲突**：英式 `ɜː` 是**不卷舌**的中央长元音，原「卷舌」人设本就名不副实；改 `ɜr` 后人设反而**恰好吻合**，但「停在口腔中部 / 拉长」必须删 |
| U18 | `ɪə` | `ɪr` | 「从前面偏高**往后往下滑到嘴巴正中央**」「一——呃」 | 「衣」+ r 尾（ear / near / deer） | **冲突**：GA 无央化双元音，不滑向 `ə` |
| U19 | `eə` | `ɛr` | 「从前面偏低**往后往下滑到嘴巴正中央**」「诶——呃」 | 「诶」+ r 尾（hair / chair / bear） | **冲突**，同上 |
| U20 | `ʊə` | `ʊr` | 「跟我做**前半段**…短促地——乌」「乌——呃」 | 「乌」+ r 尾（tour / sure） | **冲突**，同上 |

**「卷舌」措辞的误读风险（C2）**：GA 的 `/r/` 有两种常见舌型 —— 舌尖上卷（retroflex）与舌体后缩隆起（bunched），**两者都正确**，很多母语者用后者（舌尖是放低的）。原中文「舌头**卷成小弹簧**」「**要把舌头卷起来**」容易被儿童理解成「必须把舌尖往上卷」，把一种合法舌型教成唯一标准，且会把 `/r/`（U36）与 `/l/` 的对立教歪（`:1464` 的干扰项正是「要卷舌头」）。
→ **裁决**：**保留精灵人设名「卷舌弹簧」**（它是 mnemonic 资产，E1，且改后与 rhotic 吻合，是意外之喜）；但所有**讲解句**统一改为「**舌头往后收、两边轻轻卷起，带出一点 r 的尾音**」，去掉「停在口腔中部」「停在正中央」「把声音拉长」「舌尖卷起来」。表 A A35、表 B B60/B61/B66 已按此给出逐字改写。
→ **附带（已裁定：本轮不动）**：`type:"diphthong"` 对 U18/U19/U20 在美式口径下**名不副实**（应是 r 色彩元音 / 元音+r），但该值是 `atlas.js:71/72` 的分组逻辑键，**J3 禁止改**；表 E E10 已列明。4 个 rhotic 显示值本轮冻结（§6.2 R5），分类体系与章节命名的重写**另立教研终审一轮**，本轮一律不动，登记为遗留 R3。
