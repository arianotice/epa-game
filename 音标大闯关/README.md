# 声音探险队 · 音标大闯关

面向小学阶段学生的英语音标启蒙网站，采用**「滚动叙事 + 闯关游戏」双模式**：

- **📜 探险故事**（默认落地页）：电影级滚动长页面，9 个章节随滚动逐屏揭示，配色平滑过渡；
- **🎮 音标大闯关**：30 关闯关游戏，含 48 音标图鉴与毕业典礼。

内容源自《声音探险队 · 48 个音标精灵》播客（30 期正节目 + 48 个音标讲解单元）与配套知识图谱美术图（A1 大地图 / A2 元音城堡 / A3 辅音王国 / F 口腔剖面 / B 系列期配图 24 张）。

## 技术栈

| 用途 | 方案 | 说明 |
|---|---|---|
| 平滑滚动 | **Lenis.js 1.3.27** | 惯性滚动；通过 `lenis.on('scroll', ScrollTrigger.update)` + `gsap.ticker` 驱动，与 ScrollTrigger 完全同步 |
| 滚动动画 | **GSAP 3.15 + ScrollTrigger** | 逐章场景时间线 + 背景色 scrub 过渡 + 路线绘制 + 横向长廊 |
| 动画库存放 | `assets/vendor/` | **本地化**，不依赖 CDN，离线与线上均可用 |
| 降级 | `prefers-reduced-motion` | 自动关闭平滑滚动与入场动画，内容保持可见（不会白屏） |
| 进度存档 | localStorage | `ipa-quest-v1`（星星 / 收集 / 声音设置） |
| 音效 | WebAudio 实时合成 | 点击 / 答对 / 答错 / 星星 / 通关号角，无音频文件依赖 |

## 玩法（闯关模式）

1. **大地图**：A1《英语音标大地图》上分布 30 个关卡节点——出发营地 2 站、元音城堡 10 关、辅音王国 14 关、进阶峰 4 站。逐关解锁（上一关获 ≥1 星）。
2. **关卡页**：期配图 + 完整播客音频播放 + 双音标学习卡（符号/精灵名/发音要点/单词跟读/口诀）+ 记忆小窍门。
3. **听辨大挑战**：每关 5 题——听辨题（TTS 朗读最小对立对，如 sheep/ship）、音节数、重音位置、连读判断、知识题。答对 ≥3 题通关：1–3 星，收集该关音标精灵。
4. **音标图鉴**：48 个音标卡（未收集显示问号剪影），可单独播放该音的 3–4 分钟讲解音频；知识图谱页浏览 A1/A2/A3/F 四大总纲图。
5. **毕业**：30 关全清 + 48 精灵收集 → 毕业证书页。

### 路由与生命周期

- `#/story`（或空 hash）→ 叙事站；`#/map` / `#/level/EPxx` / `#/atlas` / `#/grad` → 闯关模式。
- 路由切换时 `StoryView.destroy()` 会 `gsap.context().revert()`，彻底清理 ScrollTrigger 与钉住产生的 pin-spacer，并移除背景层/导航/CTA，避免钉住残留。

## 本地运行

```bash
cd 音标大闯关
python -m http.server 8765
# 打开 http://localhost:8765
```

任何静态文件服务器均可（需 HTTP 协议，`file://` 下 localStorage 受限）。
